Docker Compose поднимает Web, API, worker, PostgreSQL, Redis, backup и автоматический TLS.

  1. ПодготовьтеLinux, Docker, домен и DNS на IP сервера.
  2. Склонируйтеgit clone https://github.com/tigramaan/ai-planner.git
  3. Создайте секретыСкопируйте `.env.example`, замените заглушки локально.
  4. Запуститеdocker compose --profile caddy up -d --build
  5. Подключите сервисыКаждый пользователь авторизует собственные календари и почту.
